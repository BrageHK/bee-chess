# Real catalog analysis: 2026-09-12

Analyzed all 105 games downloaded from `beechessjohan`, using Stockfish 18 at 100,000 nodes per position, one thread, 16 MiB hash, MultiPV 1, and fresh search state with full move history. This is a historical game sample; the catalog does not identify Bee’s build or retain its search telemetry for each move.

All 8,914 plies persisted. Restarting selected all 105 games, skipped all 105, and performed **zero searches**. A SHA-256 comparison confirmed that every move row, row ID, and game summary stayed unchanged.

Threshold counts are strict and cumulative. Mate transitions are excluded from CP averages and thresholds. Raw totals include 888 positive score drops where the stored best move equals the played move. Three of these appear in the top 50, including the largest raw drop (701cp). They are marked as analysis disagreements in the dashboard and require further analysis before being called move errors.

The phase averages are nearly tied. The endgame tail is concentrated: 14 of the 56 >200cp drops come from the single drawn game `VNfytGnY`. Its repeated king/bishop shuffling misses the same passed-pawn conversion plan. This is strong evidence for a regression candidate, but not fourteen independent failures.

The top 50 cover 29 games and 47 distinct FENs when move clocks are removed. Eleven entries start below -200cp; raw CP drops in already lost positions deserve less priority than moves that turn a holdable game into a loss.

## Local artifacts and reproduction

`data/games/catalog.sqlite3` contains the real catalog and analysis run 1. The local `full-analysis.json`, `full-analysis-reviewed.json`, and `worst-50.csv` preserve every requested field: game, ply, FEN, Bee move, best move, both mover-perspective evaluations, CPL, phase, and PV. The reviewed JSON is versioned with `review_schema_version: 1` and adds manual notes; these runtime artifacts are ignored by Git.

```sh
cargo run -p bee-games -- analyze --player beechessjohan --nodes 100000 --top 50
cargo run -p bee-games -- analysis report --run 1 --top 50 --json > data/games/full-analysis.json
```
